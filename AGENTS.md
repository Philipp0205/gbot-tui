# gbot-tui

Philipp's personal terminal UI for talking to Grok Bot. Python script + tests.

## Stack
- `gbot_tui.py` — main TUI
- `test_gbot_tui.py` — `unittest` tests
- `gbot-tui.zsh` — shell helper
- `docs/`, `bench/`

## Commands
- `python -m unittest test_gbot_tui.py`
